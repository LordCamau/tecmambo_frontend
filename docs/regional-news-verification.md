# Regional News Verification

The African tech news package added in July 2026 uses local article data with source links stored on each story. The stories are country-tagged through the regional taxonomy, so they appear in `/africa`, country hubs, feeds, markdown mirrors, and structured data through the existing content model.

Editorial handling:

- Each story includes at least one source link.
- Stories are written only from details that were found in public reporting or official pages.
- Items with incomplete timing or launch detail use cautious wording instead of stronger claims.
- No editor verification notes are left in public article fields.
- Region chips are used only when the story is about that country or materially useful to readers there.

This keeps tecMAMBO global-first while letting country context travel with the article wherever it appears.
